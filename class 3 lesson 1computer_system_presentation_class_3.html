How Does a Computer Work?

A computer follows the I-P-O Cycle!

INPUT

Giving data and commands to the computer.

PROCESS

The CPU works on the data to solve problems.

OUTPUT

Showing the final result on the screen or paper.

Hardware: The Parts You Can Touch

Hardware refers to the physical, tangible components of a computer.

Input Devices

Mouse, Keyboard, Microphone

Output Devices

Monitor, Printer, Speakers

Storage Devices

Hard Disk, CD, Pen Drive

Inside the Box

Motherboard, RAM

The Brain: CPU

Central Processing Unit

ALU (Arithmetic Logic Unit)

Does all the mathematical calculations (add, subtract) and logic comparisons.

CU (Control Unit)

The traffic cop! It controls and manages how all parts of the computer work together.

MU (Memory Unit)

Stores data and instructions temporarily so the CPU can use them quickly.

Software: The Invisible Instructions

Software are the programs you cannot touch. They tell the hardware what to do!

System Software

The main manager that runs the computer hardware.

Example: Windows, Android

Application Software

Programs designed to help you do specific fun tasks!

Example: Tux Paint, Games
