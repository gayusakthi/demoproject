Recap: Hardware & Software

Hardware

The physical parts of a computer that you can see and touch.

Examples: Keyboard, Mouse, Monitor, Storage devices.

Software

A set of instructions given to a computer to do a particular task.

It is necessary to make the hardware work! (e.g., Windows, Paint).

Types of Software: System Software

System software manages and controls the overall working of a computer system. There are two main types:

1. Operating System (OS)

The most important software! It helps hardware work with software.

  • Windows 10, Windows 8
  • Mac OS
  • Linux

2. Utility Software

Programs that manage functioning and help the computer perform better.

  • Anti-virus
  • Backup software
  • Compression software

Types of Software: Application Software

Programs that help you do specific jobs (typing, painting, playing games).

Word Processor

Helps you work on text (e.g., Microsoft Word, WordPad).

Spreadsheet

For calculations and charts (e.g., MS Excel).

Presentation

Display info in slides (e.g., MS PowerPoint).

Graphics/Multimedia

Create images/videos (e.g., Paint, Windows Media Player).

Windows 10 (GUI)

Windows is an Operating System with a Graphical User Interface (GUI). This means you operate it using graphical icons instead of typing text commands!

The Desktop

The very first screen that appears when you switch on the computer. It has small pictures called Icons.

The Taskbar

The long bar at the bottom of the home screen. It has four main parts:

1. Start Button

Found on the extreme left. Opens the Start Menu.

2. Quick Launch Area

The middle portion. Shows pinned apps and currently open programs.

3. Notification Area

On the right. Shows internet, volume, time, date, and battery status.

4. Peek Button

Extreme right edge. Pressing it hides all windows and takes you to the Desktop.

Desktop Icons

This PC

A shortcut to all drives and their content. Double-click to view files and folders.

Shortcut Icons

Direct links to programs stored elsewhere. They always have a small jump arrow in the corner.

Recycle Bin

Where deleted files go. It saves them so if you delete by mistake, they are not lost forever!

File/Folder Icons

Icons without an arrow. The file is actually saved directly on the Desktop.

Managing Start Menu Tiles

When you click the Start button, you see colorful squares and rectangles called Tiles. They are shortcuts to apps.

  • Live Tiles: Some show live updates (like the Weather or News app).
  • Pin/Unpin: Right-click an app to "Pin to Start" or "Unpin".
  • Resize: Right-click a tile to make it small, medium, wide, or large.
  • Move & Group: Click and drag tiles to move them or create named groups (like "Games").
